双人对话使用两个独立参考：

- `<|speaker:0|>` / `voice0`：火辣大厨，冻结合成男声。
- `<|speaker:1|>` / `voice1`：温暖女声，复用已有Breeze中文声音设计音频，逐字稿已做ASR辅助核对。

两个角色在最左侧分别选择参考，再经两个Drama3EncodeVoice节点编码，共用同一个codec。默认逐句生成后按脚本顺序合并，减少串音；额外保留一条`together`整段生成，供比较连贯性和角色保持。音色身份与表达效果仍需试听。

六个共享工作流模板中新增`example_workflows/drama3_dialogue.json`及同名API版。台词、种子和温度沿用左侧集中控制；生成输出位于`audio/drama3/tts-gallery/`。

后台状态位于`.generation/drama3-batch.json`，日志位于`.generation/drama3-batch.log`，均不进入Git。后台进程按任务编号等待，生成后把ASR辅助核对任务追加到队列末尾；全部结束后重建目录，仅在ComfyUI空闲时部署并重载插件。

查看状态：

```bash
python3 scripts/drama3_batch.py status
```

重新启动整理进程：

```bash
python3 scripts/drama3_batch.py start-watcher
```

已完成的任务不会再次排队；网络暂时失败时保留编号并重试。生成失败的条目保留错误记录，不用其他音频替代，也不宣称完成。ASR只核对文字，不验证音色相似度或是否成功耳语。

语法来源：[Drama3节点文档](https://github.com/PedroMarinhoDev/ComfyUI-Drama3)、[官方模型说明](https://huggingface.co/fishaudio/drama-3)。来源链接也保存在导出的工作流Note中。
